# Roadmap

Plans can change. Feedback and ideas are welcome in the issues.

## Observation (current)

- [x] Live colony, pawn, threat, base, world and map data
- [x] Game data search across the base game, DLCs and active mods
- [x] Site search with predicted mountain shapes
- [ ] Model more of the tile features that shape terrain, such as valleys and cliffs
- [ ] Show predicted water and cave tunnels in the site preview, not just rock
- [ ] Test on Windows and macOS
- [ ] Steam Workshop release
- [ ] Package the MCP server for one-command installation
- [ ] Screenshot tool, for when text is not enough
- [ ] More data as real questions reveal gaps: trade, caravan details, Anomaly and Odyssey systems

## Setup help

- [x] Choose a site and move the camera to it
- [x] Set up the ideoligion on request
- [x] Find, swap and edit colonists on request
- [ ] Fluid ideoligions, and adding relics, buildings and apparel desires
- [ ] Letting the assistant see icons, not just their names
- [ ] Colonists' worn apparel, weapons, implants, head and body shape
- [ ] The scenario, storyteller and world settings screens

## Actions (next)

Optional control of the game during play, off by default.

- [ ] Player-level actions only, the same things a player could do by hand, such as work priorities,
      research, bills and zones
- [ ] An in-game setting that enables them, and a way to approve each action
- [ ] Never cheats: spawning items, editing pawns and triggering events stay out of scope

## Compatibility

- [ ] RimWorld 1.7 and the Waylith engine, once the branch stabilizes
